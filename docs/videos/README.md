# KalamDesk lesson videos

Eight narrated, step-by-step lessons (about 22 minutes in total). Each one is a real screen recording of KalamDesk with a visible cursor, a highlighted ring around what to click, on-screen captions, and a spoken voice-over. Full HD (1920 x 1080), MP4 (H.264 video, AAC audio). Every video has a matching `.vtt` captions file.

| # | File | For | Length | What it teaches |
|---|------|-----|--------|-----------------|
| 1 | `01-welcome.mp4` | Everyone | 2:49 | Accept the invitation, choose a password, sign in, privacy notice, first look at My Day and the menu |
| 2 | `02-myday.mp4` | Everyone | 3:02 | My Day, statuses, Mark done, quick add (type a task in plain words), checklist, comments |
| 3 | `03-standup.mp4` | Everyone | 2:28 | Daily stand-up, Board, List, Calendar, notifications |
| 4 | `04-business.mp4` | Everyone | 2:57 | Leave and attendance, leads, expense claims, school visit reports |
| 5 | `05-rewards.mp4` | Everyone | 2:14 | Scores, challenges, kudos, incentives, referrals |
| 6 | `06-settings.mp4` | Everyone | 2:31 | Password, calendar link, privacy, two-step sign-in |
| 7 | `07-founders.mp4` | Managers and founders | 3:25 | The Desk, adding a person, recurring tasks, approving leave and expenses, dashboard |
| 8 | `08-owners.mp4` | Group owners | 3:08 | Several organisations, the switcher, creating an organisation |

Suggested order for a new employee or intern: 1, 2, 3, 6, then 4 and 5 when they are needed.

## Uploading

- **YouTube (Unlisted)** or **Google Drive**: upload the `.mp4`. On YouTube, open *Subtitles* and upload the matching `.vtt` file so viewers can turn captions on. Use *Unlisted*, not *Public*, so only people with the link can watch.
- **WhatsApp / email**: each file is 7 to 15 MB, small enough to send directly.
- The videos use demo names and data (Robokalam and Samaritan Stand-Up demo people). No real information appears in them.

## Re-recording

The recordings are generated by a script, so they can be regenerated if the app changes. The voice is Microsoft's neural voice *Neerja* (Indian English), produced with the free `edge-tts` tool, which sends the narration text (not any customer data) to Microsoft's text-to-speech service.
